# Mis Garantías

El objetivo de esta aplicación es poder mantener las garantías de mis compras y productos.

Será una aplicación enteramente local con SQLite por ahora.

# Este es el stack de tecnologías que voy a utilizar.

- React Native
- Expo
- TypeScript
- Expo Router
- Expo SQLite - https://docs.expo.dev/versions/latest/sdk/sqlite/
- Expo Secure Store
- Expo Location
- Expo Camera
- Expo FileSystem
- Expo Crypto
- Zustand
- React Query

## Patron y arquitectura

- Arquitectura limpia, siguiendo la skill de Clean Architecture. @.claude/skills/clean-architecture

## Procedimiento:

1. Ordenar archivos iniciales
2. Entidades y reglas
3. Tests de dominio
4. Contratos de dominio
5. Implementación de Contratos de dominio
6. Casos de uso
7. UI de Productos y Garantías
